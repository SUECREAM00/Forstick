# 13장 기대 효과 — 조사 프롬프트

아래 블록 전체를 리서치 도구에 그대로 붙여 넣는다. (Claude 초안 → Codex 검토·보완, 2026-10-12)

```text
당신은 산업용 로봇·인간-로봇 상호작용(HRI) 분야의 리서처다.

[목표]
(조사 기준일: 2026-10-12)
“자연어로 로봇에 작업을 지시·변경할 수 있게 될 때, 누가 어떤 혜택을 얼마나 얻는가?”를 조사하라.

발표자료의 ‘기대 효과’ 장에 사용할 이해관계자 약 3개와 정량 지표를 선정하는 것이 목적이다. 큰 숫자를 찾기보다 자연어 지시와 혜택 사이의 인과적 연결, 비교 조건, 계산 가능성을 우선하라.

실제 제품 성능 자료는 제공되지 않았다. 외부 연구 결과를 우리 제품의 실적·보장 성능처럼 표현하지 마라.

[1. 조사 범위와 이해관계자]
한국의 다품종 소량생산 제조 현장에서 산업용 로봇·협동로봇의 작업을 설정하거나 변경하는 상황을 중심으로 조사하라.

우선 후보:
① 현장 작업자: 작업 지시·변경 시간과 독립 수행 능력
② 제조 중소기업의 생산책임자·경영자: 연간 운영 공수와 비용
③ 로봇 SI 업체의 구축·유지보수 엔지니어: 프로젝트 구축·변경·지원 공수

안전관리자와 교육·훈련기관은 대안으로 검토하라.
후보별로 직접 수혜 여부, 구매·사용 역할, 정량 근거의 질, 다른 카드와의 중복을 평가하고 최종 3개를 추천하라.
SI 대신 안전관리자나 교육기관을 추천한다면 교체 이유와 더 강한 근거를 제시하라.
근거가 부족하다는 이유만으로 문제 규모 지표를 혜택 수치로 채우지 마라.

[2. 기술 범위 구분]
다음 기술을 구분하여 기록하라.
- LLM 기반 자연어 작업 계획·프로그램 생성 및 수정
- 규칙 기반 자연어 또는 제한된 음성 명령
- GUI·블록·AR·시연 기반 프로그래밍
- 위 기술과 비전·자동 계획·스킬 라이브러리·검증 기능을 결합한 시스템

텍스트 입력과 음성 입력, 기존 스킬 호출과 신규 프로그램 생성을 구분하라.
시스템 전체의 효과만 측정했다면 자연어 입력 자체의 효과라고 주장하지 마라.

[3. 현재 슬라이드 수치 감사]
다음 수치를 원문까지 추적하고 유지·조건부 사용·교체를 판정하라.

A. Perzylo 외, IROS 2016:
기어박스 조립 프로그래밍 48분→8분, 약 83% 단축.
참가자 1명 예비연구라는 설명의 정확성, 최초 작성과 변경 작업의 구분,
실제 입력 방식, 사전 구축된 지식·스킬, 시간 측정 범위를 확인하라.

B. 중기부 ‘2024년 스마트제조혁신 실태조사’:
인력 확충 애로 중 비용 부담 47.1%.
모집단, 응답 대상, 질문 문구, 복수응답 여부, 분모를 확인하라.

C. 2014~2024년 산업용 로봇 산재 사망 26명,
비정형 작업 사고 중 약 83%가 로봇 미정지 상태였다는 수치:
세계일보 2026.04.27 보도와 고용노동부 원자료를 추적하라.
두 수치의 기간·대상·분모가 같은지, 사고 발생 기준인지 승인 기준인지 확인하라.
원자료를 못 찾으면 ‘언론의 원통계 인용, 원자료 미확인’이라고 표시하라.

D. 스마트공장 관련 교육 예산 별도 보유 기업 6.6%:
모집단·분모를 확인하고 교육기관의 혜택을 직접 설명하는 수치인지 평가하라.

각 수치를 ‘문제 규모 / 직접 관측된 효과 / 조건부 추정’으로 분류하라.

[4. 이해관계자별 조사 지표와 계산]
① 현장 작업자
주지표: 동일 작업의 지시·프로그램 변경 완료 시간(분/건).
보조지표: 기준 시간 내 독립 수행률, 수정 횟수, 숙달 시간, 인지 부담.

계산:
- 절감 시간 = 기존 시간 - 자연어 방식 시간
- 단축률 = 절감 시간 / 기존 시간 × 100
- 수행률 개선은 %p와 상대 증가율을 구분

필수 조사:
참가자 수와 숙련도, 작업·로봇 종류, 비교 인터페이스,
사전 교육, 사전 작성된 코드·스킬, 실험 순서와 학습효과 통제,
입력·시스템 대기·검증·수정·실패 복구의 포함 여부,
성공 기준, 제한 시간, 실패·중도탈락 처리,
평균/중앙값, 분산·신뢰구간·통계검정의 보고 여부.
완료 시간은 성공률과 함께 제시하고 성공한 사례만으로 유리하게 비교하지 마라.

② 제조 중소기업
주지표: 연간 확보 노동시간(시간/기업 또는 로봇 셀)과 비용 가치(원/년).

계산:
- 적용 가능한 연간 변경 건수 = 전체 변경 건수 × 적용 가능 비중
- 확보 노동시간 = 적용 가능한 변경 건수 × 건당 절감 인시
- 노동시간 가치 = 확보 노동시간 × 국내 시간당 총인건비
- 순비용 효과 = 입증된 비용 절감 - 추가 도입·교육·운영 비용

필수 조사:
국내 기업의 작업 변경 빈도, 실제 참여 인원, 적용 가능한 공정 비중,
총인건비의 직종·연도·산정 범위, 구독·추론·유지보수비,
초기 통합·교육 비용과 분석 기간.
분/건과 인분/건을 구분하고 시간 단위를 통일하라.

노동시간 가치와 현금 지출 감소를 구분하라.
생산중단 감소는 실제 설비 중단 시간이 측정된 경우에만 별도 계산하라.
매출 전체를 시간당 손실로 사용하지 마라.
가동시간 증가를 생산량·매출 증가로 바꾸려면 병목, 수요, 가동 조건 근거가 필요하다.
중복 비용을 합산하지 마라.

③ 로봇 SI 업체
주지표: 프로젝트 또는 변경 요청 1건당 순투입 공수(인시).

계산:
- 순절감 공수 = 단계별 기존 공수 합계 - 도입 후 공수 합계
- 비용 효과 = 순절감 공수 × 시간당 원가 - 추가 비용

필수 조사:
요구사항 정의, 프로그램 작성, 디버깅, 검증, 현장 조정,
고객 교육 및 사후 지원 단계별 공수.
스킬·API 연결과 템플릿 구축의 초기 공수,
재사용 가능한 프로젝트 수, 추가 검증과 모델 변경 유지보수 비용.
초기 구축과 반복 사용을 분리하라.
처리 용량 증가와 실제 수주·매출 증가를 구분하라.

④ 대안 지표
안전관리자:
동일 검증 품질에서의 검토 시간, 위험 명령 차단률,
정상 명령 오차단률, 미탐지율, 정지 처리 지연.
위험·정상 시나리오의 분모와 실제 로봇 정지 확인 여부를 조사하라.
자연어 기능과 별도 안전 검증 장치의 효과를 분리하라.
사고 통계만으로 사고 감소율·예방 사망자 수를 계산하지 마라.

교육기관:
동일 숙달 기준까지의 교육 시간, 강사 개입 인시,
학습자 1인당 장비 점유 시간·교육 비용.
학습 성취, 실제 로봇으로의 전이, 장비·시뮬레이터 비용을 함께 조사하라.
교육 시간이 짧다는 이유만으로 교육 효과가 높다고 판단하지 마라.

LLM끼리 비교한 개선율을 티칭펜던트 대비 개선율로 바꾸지 마라.
개선이 없거나 성능이 악화된 결과도 포함하라.

[6. 출처·최신성·한국 적용 기준]
효과 수치는 동료심사 논문 및 원문 사용자 연구를 우선하라.
프리프린트, 기업 사례, 보도자료는 유형과 한계를 표시하라.
학회명이나 최신 연도만으로 근거가 강하다고 판단하지 마라.

국내 배경·비용 자료는 중기부, 고용노동부, 국가통계,
한국로봇산업진흥원 등 원자료를 우선하라.
최신 공개 자료를 찾되 발표일과 실제 조사·관측 기간을 모두 기록하라.

해외 실험과 한국 비용을 결합하면 ‘한국 조건을 적용한 시나리오 추정’이라고 표시하라.
한국어, 현장 소음, 방언, 로봇 기종, 작업 난도, 숙련도 차이를 검토하라.
조건 차이를 보정할 근거가 없으면 임의의 보정률을 만들지 마라.

각 핵심 수치에는 제목, 저자·기관, 연도, URL/DOI,
페이지·표·그림 또는 절 번호를 붙여라.
원문 미열람·초록만 확인한 수치는 확정 근거로 추천하지 마라.
동일 연구의 논문·보도자료·재인용 기사를 독립 근거로 세지 마라.

[7. 과장 방지 규칙]
- 모든 숫자를 ‘외부 연구 실측 / 조건부 계산 / 미검증 목표 / 문제 규모’로 표시한다.
- 표본 수, 비교군, 실험 환경과 평가 단위가 없는 개선율은 우선 추천하지 않는다.
- 참가자 수와 반복 시행 수를 구분한다.
- 서로 다른 연구의 최대 개선율만 골라 결합하지 않는다.
- 위험 집단 비율, 채용 애로 비율, 예산 보유율에 시간 단축률을 곱하지 않는다.
- 같은 시간 절감을 작업자·기업·SI 카드에서 보여줄 수는 있지만 사회 전체 편익으로 중복 합산하지 않는다.
- SUS나 NASA-TLX 점수를 생산성·비용 절감률로 환산하지 않는다.
- 음성 정지 요청을 인증된 비상정지나 실제 정지 성능으로 간주하지 않는다.
- 비용·시간 증가는 음수 효과로도 보고하며 숨기지 않는다.
- 확인되지 않은 입력값은 ‘자료 없음’으로 두고, 임의 수치로 계산을 완성하지 않는다.
- 근거가 부족하면 ‘혜택 수치 확정 불가’라고 쓰고 필요한 현장 측정을 제안한다.

[8. 출력 형식]
먼저 최종 이해관계자 3개와 선정 이유를 5문장 이내로 제시하라.

표 A. 기존 슬라이드 감사

표 B. 효과 연구 근거
```
