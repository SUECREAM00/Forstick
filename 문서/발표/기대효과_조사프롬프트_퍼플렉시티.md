# 13장 기대 효과 — 퍼플렉시티용 프롬프트 (2026-10-12)

퍼플렉시티는 한 번에 하나의 질문에 집중할수록 정확하다. **1번(메인)을 먼저 돌리고**, 부족한 부분만 2~4번(이해관계자별)으로 따로 물어본다. 모드는 Research(Deep Research) 권장.

---

## 1. 메인 프롬프트

```text
[배경]
우리 서비스는 작업자가 한국어 음성·텍스트로 산업용 로봇(협동로봇)에 작업을 지시하면, LLM이 작업 계획을 만들고 안전 검증·사람 승인을 거쳐 실행하는 시스템이다. 대상 현장은 한국의 다품종 소량생산 중소 제조기업이다.

[질문]
"티칭펜던트·코딩 대신 자연어로 로봇 작업을 지시·변경할 수 있게 되면, 누가 어떤 혜택을 얼마나 얻는가?"
아래 이해관계자 중 근거가 가장 강한 3곳을 고르고, 각자가 얻는 혜택을 검증 가능한 수치로 제시하라.
- 현장 작업자(비전문가): 작업 지시·변경 시간, 교육(숙달) 시간, 성공률
- 제조 중소기업(경영·생산 관리자): 작업 변경 비용·시간, 외부 SI 의존, 로봇 담당 인력 부족
- 로봇 SI(시스템 구축) 업체: 프로그래밍·시운전·유지보수 공수
- 안전 관리자: 실행 전 검증으로 줄어드는 위험·검토 시간
- 교육·훈련 기관: 로봇 교육 시간·비용

[찾아야 할 근거]
1. 자연어(LLM 포함)·직관적 로봇 프로그래밍과 기존 방식(티칭펜던트·코드)을 비교한 사용자 실험: 작업 완료 시간, 성공률, 교육 시간, 오류 수정 횟수. 2023~2026년 연구 우선.
2. 한국 현장 규모 자료: 로봇 작업 변경 빈도·소요시간, 로봇 운용 인력 부족, SI 비용, 인건비(중소벤처기업부, 고용노동부, 한국로봇산업진흥원, 통계청 등 원자료).
3. 산업용 로봇 사고 중 티칭·정비·비정형 작업 비중(고용노동부·안전보건공단 원자료).

[규칙]
- 수치마다 출처(기관·제목·연도·링크)와 원문 문장을 붙여라. 원문을 확인하지 못한 수치는 쓰지 마라.
- 각 수치를 "직접 효과(자연어·직관 방식 실험 결과)" / "문제 규모(통계)" 중 하나로 표시하라.
- 참가자 수, 비교 대상, 실물/시뮬레이션 여부를 함께 적어라. 참가자가 적은 예비 연구는 그렇다고 밝혀라.
- 서로 다른 비율을 곱하거나, 해외 실험 결과를 한국 효과로 단정하지 마라. 한국 비용을 적용한 계산은 "추정"이라고 표시하라.
- 찾지 못하면 "자료 없음"이라고 쓰고 지어내지 마라.

[출력]
1) 최종 이해관계자 3곳과 선정 이유(3문장 이내)
2) 표: 이해관계자 | 혜택 | 수치(단위) | 직접 효과/문제 규모 | 조건(참가자 수·비교 대상·환경) | 출처·연도·링크
3) 발표 카드용 한 줄 요약 3개(이해관계자별 대표 수치 1개씩, 한계 각주 포함)
```

## 2. 현장 작업자 (부족할 때)

```text
LLM 기반 자연어 로봇 프로그래밍 또는 직관적(비코딩) 로봇 프로그래밍을 티칭펜던트·코드 방식과 비교한 사용자 실험을 2023~2026년 중심으로 찾아줘.
작업 완료 시간, 성공률, 교육(숙달) 시간, 오류 수정 횟수를 수치로 정리하고, 참가자 수·숙련도·로봇 종류·실물/시뮬레이션 여부·비교 대상을 함께 적어줘.
영문 키워드: "large language model" "robot programming" "user study", "natural language robot programming" "task completion time", "end-user robot programming" "teach pendant".
원문 링크와 해당 표·페이지를 붙이고, 확인 못 한 수치는 빼줘.
```

## 3. 제조 중소기업 (부족할 때)

```text
한국 중소 제조기업(다품종 소량생산)에서 산업용·협동로봇의 작업 변경(품종 교체·재프로그래밍)에 드는 시간·비용, 외부 SI 업체 의존 정도, 로봇 운용·프로그래밍 인력 부족 현황을 보여주는 공식 통계나 조사를 찾아줘.
중소벤처기업부 스마트제조혁신 실태조사, 한국로봇산업진흥원 로봇산업 실태조사, 고용노동부·통계청 자료를 우선하고, 조사 연도·모집단·분모를 함께 적어줘. 원문 링크 필수, 없으면 "자료 없음".
```

## 4. 안전 관리자 또는 SI 업체 (세 번째 카드 비교용)

```text
(a) 한국 산업용 로봇 사고·사망 통계 중 티칭·정비·비정형 작업 중 발생 비중을 고용노동부·안전보건공단 원자료로 찾아줘. 기간·분모·집계 기준을 함께 적어줘.
(b) 로봇 시스템 통합(SI) 프로젝트에서 프로그래밍·시운전·유지보수가 차지하는 공수나 비용 비중을 보여주는 자료를 찾아줘.
두 자료 중 "자연어 로봇 작업 지시"의 혜택을 수치로 더 직접 보여줄 수 있는 쪽이 어디인지도 판단해줘. 출처 링크 필수.
```
