# QA 자동화 진행 현황 (자동 재개용)

이 파일은 작업이 끊겨도(일일 사용량 초과 등) 다음 실행이 이어서 하도록 남기는 기록이다.
자동 재개 작업(1시간마다, 세션 안 cron)이 이 파일을 읽고 "다음 할 일"부터 이어 간다.

## 목표 (사용자 요청 2026-10-02)
- 프로젝트 요구사항(기획서 SFR·NFR·TER, 화면설계서 ①~㉗, 상태매트릭스, 개발 중 반영된 결정)이
  전부 구현됐는지 **QA 테스트를 자동화**해서 판정한다.
- 사용자 결정이 필요한 것은 판정하지 않고 "결정 필요"로 남긴다.

## 원칙
- 백엔드 코드는 고치지 않는다(메모리: 백엔드는 수정하지 않음). 백엔드는 API로만 본다(블랙박스).
- 팀원 PC의 Gazebo 로봇을 **움직이는 명령은 보내지 않는다**(승인 버튼 누르지 않음). 그런 검사는 "결정 필요".
- 서버가 꺼져 있으면 서버 의존 검사는 "미실행"으로 적는다 — 통과로 치지 않는다.
- 구현 안 된 기능은 실패로 정직하게 남긴다(테스트를 약하게 만들지 않는다).
