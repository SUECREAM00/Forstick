# 발표집 원고 (포스틱)

> 표지 제목(안): **한국어 음성 명령 기반 로봇 작업 계획 생성 및 안전 검증 시스템**
> 팀명: (기입)

---

## 01. 프로젝트 소개

- 산업용 로봇은 작업이 바뀔 때마다 티칭펜던트나 전용 프로그래밍으로 다시 설정해야 해서 비전문가가 다루기 어렵다. 이를 해소하기 위해 작업자가 한국어 음성으로 지시하면 작업 계획을 만들고, 실행 전에 안전성을 검증하는 로봇 작업지시 시스템을 개발하고자 한다.
- 음성을 faster-whisper로 텍스트로 바꾸고, LLM(Qwen3-8B)이 정해진 스킬만으로 JSON 작업 계획을 만든다. 계획은 형식·안전 규칙·MoveIt2 충돌 검증을 거쳐 허용(PASS)·확인(ASK)·차단(BLOCK)으로 판정되며, 통과한 계획만 실행한다.
- FR3 로봇 팔과 G1 휴머노이드가 있는 Gazebo 가상 작업 셀에서 자재 이송·복귀·이동을 수행하며, 웹 대시보드에서 음성 명령, 3D 작업 셀 화면, 로봇 관리, 작업 기록 기능을 제공한다.

## 02. 프로젝트 특장점

- 한국어 음성 명령을 로봇이 수행할 수 있는 작업 계획으로 자동 변환
- AI는 계획만 만들고, 실행 여부는 별도 검증 단계가 판단하여 안전성 확보
- 모호한 명령은 확인 카드로 재확인하고, "멈춰"는 AI를 거치지 않고 즉시 정지
- 로봇 팔과 휴머노이드를 하나의 웹 화면에서 선택하여 지시

## 03. 프로젝트 개발 내용

**음성 인식(STT)**
- faster-whisper로 음성을 텍스트로 변환하고, Silero VAD로 발화 구간만 골라 전사
- WebSocket으로 마이크 음성(PCM16)을 실시간 수신, 중간 전사는 표시만 하고 최종 전사만 명령으로 사용
- 전사 제한시간과 동시 처리 한도를 두어 잡음·긴 신호가 서버를 붙잡지 않도록 처리

**작업 계획 생성(LLM)**
- vLLM으로 Qwen3-8B-AWQ 모델을 자체 서버에 호스팅
- 스킬·위치·자재 목록을 카탈로그에서 읽어 프롬프트와 출력 JSON 스키마를 자동 생성
- 정지 명령은 LLM을 거치지 않고 바로 정지 계획으로 처리, 사용자 발화는 별도 블록으로 분리하여 프롬프트 공격 차단
- 모델 출력은 JSON 파싱 → 스키마 버전 → Pydantic 구조 검사 → 카탈로그 대조를 모두 통과해야 계획으로 인정

**안전 검증 및 실행 허가**
- 규칙 기반 안전 검증기로 인자·순서·파지 상태·한계값 등 9개 규칙 검사, 결과를 PASS·BLOCK·정보 부족으로 집계
- 로봇 능력 프로필 기반 사전 검사(스킬 지원, 관절·속도·가속도·그리퍼 범위 8개 항목)
- MoveIt2로 역기구학·관절 한계·충돌 검사, 관측이 없거나 오래되면 통과시키지 않고 재확인(ASK)
- 실행 직전 현재 관측값으로 다시 판정(Execution Permit)하고, 실행 후 목표 상태와 실제 결과를 대조

**시뮬레이션 작업 셀 및 로봇 연동**
- ROS 2, Gazebo, MoveIt2, ros2_control로 FR3 로봇 팔·그리퍼·팔레트·컨베이어 작업 셀 구성
- 로봇 공통 어댑터와 레지스트리로 FR3·G1을 같은 방식으로 연결
- 실행 전 MoveIt 장면을 Gazebo 자재 위치와 동기화, 컨베이어 빈 칸 배정과 빈 위치 자동 선택
- 정지 시 체크포인트 저장, 재개 시 장면·자재·관절 상태를 다시 관측하여 검증 후 실행

**서버 및 데이터베이스 구축**
- uvicorn 기반 ASGI 서버로 HTTP API와 WebSocket(이벤트·음성) 제공, 세션별 이벤트 분리
- SQLite에 요청·계획·검증·실행 허가·실행 결과·STT 기록·로그인 계정 등 19개 테이블 구성
- 서버는 Repository 계층을 통해서만 DB에 저장하고, 브라우저는 DB에 직접 접근하지 않음
- 저장 전 API 키·토큰 등 비밀정보 자동 제거, 모든 판정에 이유 코드 기록

**웹 구축 및 테스트**
- Figma로 화면 설계 후 React, Vite로 관제 대시보드 구현, Three.js로 3D 작업 셀 화면 구현
- 구글 OAuth 로그인, 브라우저 TTS 음성 안내, nginx로 배포
- Python 단위 테스트와 Playwright 기반 화면·API·종단 간(E2E) 테스트

## 06. 프로젝트 기대효과 및 활용분야

**1) 기대효과**
- 로봇 전문지식이 없는 작업자도 말로 작업을 지시할 수 있어, 작업 변경 시 로봇 재설정에 드는 시간과 비용을 줄일 수 있다.
- 충돌·도달 불가·모호한 명령을 로봇이 움직이기 전에 차단·재확인하고 즉시 정지할 수 있어, 로봇 작업 중 발생할 수 있는 안전사고 예방에 기여한다.

**2) 활용방안**
- 작업 변경이 잦은 다품종 소량생산 제조 현장의 로봇 작업지시 도구로 활용하고, 실제 로봇 연동으로 확장할 수 있다.
- 실물 로봇 없이 작업 계획과 안전 판정을 실습할 수 있어, 로봇·스마트팩토리 교육 환경으로 활용할 수 있다.
- 저장 계층을 분리해 두어, 여러 작업 셀의 기록을 통합 관리할 때 PostgreSQL 기반 클라우드 DB(Supabase 등)로 확장할 수 있다.
