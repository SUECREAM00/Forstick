# 대시보드 — 피그마 비교 화면(`-figma` 라우트) 작업 정리

작성일: 2026-09-17

## 1. 배경 및 목적

기존 대시보드(`/`, `/robots`, `/history`, `/diagnostics`, `/settings`)는 그대로 유지한 채,
피그마 디자인 시스템(`대시보드 디자인 시스템 v1`, fileKey `qfqONZ8vSydYxrrPVPD88G`)의 구조를
반영한 새 레이아웃을 **별도 비교용 라우트**로 만들어 기존 화면과 나란히 놓고 비교하기 위한 작업.
기존 화면은 한 줄도 수정하지 않는 것을 원칙으로 진행함.

## 2. 최종 구조: 3열 레이아웃

모든 `-figma` 라우트는 아래 3열 구조를 공유한다.

1. **좌측** — 통합 사이드바 (`SidebarFigma`)
   - 피그마 참고안의 아이콘 레일 + 라벨 사이드바를 하나로 병합
   - 색상은 피그마 아이콘 레일 참고 스크린샷의 **다크 톤**(`#1c1c1f` 배경)을 그대로 사용하되,
     폭은 라벨이 함께 들어가도록 넓게 유지 (아이콘만 있는 좁은 레일 아님)
   - 메뉴: 현황 / 로봇 관리 / 기록 / 진단 / (워크스페이스) 설정
2. **중앙** — 명령 패널 (`CommandPanel`, 기존 컴포넌트 재사용)
   - 기존 앱에서는 화면 오른쪽에 있던 자연어 명령/즉시정지 패널을 이 구조에서는 **중앙 열**로 이동
   - 페이지별로 독립된 로컬 상태(`scenario`/`online`/`emergency`)를 가짐 (다른 화면과 공유하지 않음)
3. **우측/본문** — 각 화면의 실제 콘텐츠
   - 기존 `Overview` / `RobotManagement` / `History` / `Diagnostics` / `Settings` 내부 컴포넌트를
     그대로 재사용 (로직 중복 없음), 시각 스타일만 `.fx-app-shell` 스코프 CSS로 재정의

공통 셸은 `FigmaPage` 컴포넌트(`App.jsx`)로 추출해 5개 라우트가 함께 사용한다.

## 3. 추가된 라우트

| 경로 | 대응하는 기존 화면 | 비고 |
|---|---|---|
| `/settings-figma` | `/settings` | 최초로 만든 비교 화면. 색상 토큰은 사용자가 제공한 디자인 분석 문서 기준으로 직접 보정 |
| `/overview-figma` | `/` (현황) | |
| `/robots-figma` | `/robots` (로봇 관리) | |
| `/history-figma` | `/history` (기록) | |
| `/diagnostics-figma` | `/diagnostics` (진단) | |

기존 라우트는 전혀 변경하지 않았고, 사이드바 메뉴 링크는 `-figma` 라우트끼리만 서로 연결된다
(즉, `-figma` 화면 안에서는 계속 `-figma` 화면끼리 이동).

## 4. 시각 톤 다듬기 이력

1. 1차: `/settings-figma`를 만들면서 Codex가 임의로 보라색 계열 색상을 사용 → 사용자가 제공한
   정밀 디자인 분석 문서(CSS 커스텀 프로퍼티, WCAG 대비 계산 포함)의 토큰으로 직접 교체.
2. 2차: 사이드바가 요청한 참고안과 다르다는 피드백 → 다크 아이콘 레일 참고안의 색상으로 재조정
   (폭은 넓게 유지, 라벨 포함).
3. 3차: "전체적으로 모던하지도 미니멀하지도 않다"는 피드백 → `현황/로봇관리/기록/진단`이 기존
   구형 ink 테마(두꺼운 2px 테두리, 회색 박스형 구분선, 진한 그림자)를 그대로 물려받아 fx 셸과
   어울리지 않던 문제를 해결. `.fx-app-shell` 스코프 아래에서 카드·리스트·테이블·타임라인·명령
   패널 내부 요소들을 전부 통일된 라운드(12~16px), 옅은 테두리(`--fx-border`), 그림자 제거로 재정의.

## 5. 로컬 네트워크 공유

- 기본 dev 서버(`127.0.0.1:5173`)는 로컬 전용이라 외부 공유 불가.
- 같은 네트워크 내 공유를 위해 `--host` 옵션으로 별도 포트(5174)에 dev 서버를 추가로 띄움.
- 공유 링크: `http://<내부 주소>/settings` (같은 Wi-Fi/사내망에서만 접속 가능, 외부 인터넷 노출 아님)
- 공유가 끝나면 이 임시 서버(5174)는 종료 필요.

## 6. 다음에 이어갈 수 있는 것

- `-figma` 구조가 최종안으로 확정되면, 기존 라우트를 이 구조로 교체할지 계속 병행할지 결정 필요
  (현재는 사용자가 "새 비교 라우트 추가"를 선택해 병행 중).
- 시각적으로 아직 다듬을 부분이 남아 있다면 화면/요소 단위로 구체적 피드백을 받아 계속 보정.
