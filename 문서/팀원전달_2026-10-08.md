## 4. 그 밖에

- **관절 한계 시험**(브랜치 `test/joint-limit`, 임시): FR3는 Gazebo에서 속도·위치 한계를 넘지 않음. 단 중력이 관절을 한계 쪽으로 누르면 한계에서 잠겨 안 돌아오는 Gazebo 쪽 현상이 있음(그리퍼 주석의 "한계에서 잠긴다"와 같아 보임). 작업 셀 자세들은 중력 받는 관절이 한계에서 1.48 rad 이상 떨어져 있어 시연 중 생길 가능성은 낮음.
- **대시보드 QA**: `bash dashboard2/e2e/run_qa.sh [server]` 한 번으로 서버 없이 도는 검사 전부(+서버 API 읽기). 로봇 이동 검사는 돌리지 않는다. 서버 주소는 `FORSTICK2_BACKEND_URL=https://<운영 서버 주소>`.
- 운영 서버 환경변수에 `FORSTICK2_REQUIRE_LOGIN=0` — 로그인 없이 쓰이고 있다(의도인지 확인 부탁).
