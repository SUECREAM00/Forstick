## 핵심 발견

### 1. 화면 폭이 1280px 아래로 줄어들지 않는다 (가장 큰 문제)

`dashboard2/src/styles.css:32`의 `.app { min-width: 1280px }` 때문에 폭 1024와 820에서도 페이지 폭이 1280으로 유지된다(캡처 이미지 폭이 각각 1280, 1280). 태블릿에서는 **가로 스크롤**이 생기고, 오른쪽 끝에 있는 **통합 작업 명령 패널과 비상 정지 버튼 일부가 화면 밖**으로 밀린다.

- 820 세로 태블릿: 화면에는 왼쪽 820px만 보인다. 명령 패널은 x=856~1256에 있어서 스크롤하지 않으면 보이지 않는다. 비상 정지 버튼(x≈1133~1256)도 마찬가지다.
- 관제 화면에서 비상 정지가 가로 스크롤 뒤에 숨는 것은 안전 측면에서 우선 고칠 문제다. (화면에서 직접 스크롤해 확인한 것은 아님. 캡처의 좌표로 추정)

### 2. 반응형 설정이 전혀 없다

`styles.css`에 화면 폭별 규칙(`@media`)이 0개다. `index.html`의 viewport 설정만 있다.

### 3. 폭이 좁아질 때 깨지는 부분 (캡처에서 확인)

| 위치 | 증상 |
|---|---|
| 홈 · 작업 진행 내역 표 | 오른쪽 열(안전 검증, 상태)이 잘림. 1024에서 이미 `PASS (안전`이 잘린다 |
| 홈 · 로봇 카드 3개 | 카드 폭이 줄면서 "현재 작업"과 값이 붙어 읽기 어렵고, 이름이 두 줄로 꺾인다 |
| 로봇 관리 · 도구 사양 표 | 오른쪽 열이 잘려 "점검 내용 및 조치"가 읽히지 않는다 |
| 기록 및 로그 · 필터 줄과 표 | 필터(안전 검증 상태)와 표의 오른쪽 열이 명령 패널 아래로 겹치거나 잘린다 |
| 하단 DEMO 바 | 좁은 폭에서 화면 하단 중앙에 떠서 표 일부를 덮는다 (홈 1024 캡처) |
| 사이드바 | 항상 240px 고정. 태블릿에서 본문 폭을 크게 줄인다 |
| 큰 화면 아래쪽 | 820 세로에서 아래쪽이 넓게 비어 있다 (내용은 위쪽에 몰림) |

### 4. 문제가 없는 것

- 1440 데스크톱은 깔끔하다. 3열 구성(사이드바 / 본문 / 명령 패널)이 의도대로 나온다.
- 설정 화면과 실시간 진단 화면은 내용이 적어서 비교적 덜 깨진다.

## 반응형 설계에 필요한 결정 (피그마 기준안 전에 정할 것)

1. **사이드바**: 태블릿 세로에서 240px 고정을 유지할지, 아이콘만 남기는 좁은 레일로 접을지, 상단 메뉴로 바꿀지.
2. **명령 패널(오른쪽 열)**: 태블릿에서 본문 아래로 내릴지, 접었다 펴는 서랍으로 만들지. 비상 정지는 어떤 폭에서도 항상 보여야 한다(고정 배치).
3. **표**: 좁은 폭에서 가로 스크롤 / 중요한 열만 남기기 / 카드 목록으로 바꾸기 중 무엇으로 할지.
4. **로봇 카드 3개**: 세로 태블릿에서 3열을 유지할지 1~2열로 줄일지.
5. **하단 DEMO 바**: 데모 전용이라면 좁은 폭에서 숨기거나 위치를 옮길지.

## 제안하는 중단점(breakpoint)

| 이름 | 폭 | 근거 |
|---|---|---|
| 데스크톱 | 1280 이상 | 현재 디자인 그대로 |
| 태블릿 가로 | 1024~1279 | 3열 유지, 사이드바 축소 |
| 태블릿 세로 | 768~1023 | 명령 패널을 아래로 또는 서랍, 표는 핵심 열만 |

### 변경: 명령 패널을 서랍에서 버튼 아래 팝업으로 (2026-09-30)

- 결정: 태블릿에서 명령 패널은 헤더의 `명령 패널` 버튼을 누르면 버튼 아래에 떠오르는 카드(폭 400px)로 연다. 세로로 긴 서랍은 쓰지 않는다. 이유: 뒤 화면을 덜 가리고, 글자를 입력할 때 화상 키보드가 아래를 덮어도 입력창이 위쪽에 있어 가려지지 않는다.
- 프레임: `Home / Tablet portrait 820 - 명령 패널 팝업 (버튼 아래)`, `Home / Tablet landscape 1024 - 명령 패널 팝업 (버튼 아래)` (1024 프레임은 y=2600)
- 표현: 열린 상태의 버튼은 어두운 청록으로 눌린 색, 팝업 위쪽에 버튼을 가리키는 작은 화살표, 뒤 화면은 30%만 어둡게, 카드에 그림자
- 코드로 옮길 때 명세에 넣을 것(피그마에는 표현 안 됨): 패널 바깥을 누르거나 Esc를 누르면 닫힘, 열려 있는 동안에도 비상 정지는 항상 눌러야 함, 뒤 화면은 스크롤 잠금
- 화면 높이(820 세로 1180 / 1024 가로 768)에 맞춘 프레임이라 아래쪽 내용은 잘려 보이는 것이 정상
